# 라인조명 4. 제어기 설정

기기 화면 → **⚙️ 설정** 탭에서 LED 개수, 구간 나누기, 전류, 화면 테마, 펌웨어를 확인하고 바꿉니다.
그룹의 마스터 화면에서는 **설정 대상**을 골라 슬레이브의 설정도 볼 수 있습니다.

## LED 개수

### 자동 감지

**자동 감지** 를 누르면 제어기가 전류 변화를 보며 LED를 한 알씩 켜서 **연결된 LED 수를 스스로 셉니다.**

- 측정하는 동안 화면에 **"LED 자동 측정 중"** 이 뜨고 조명이 꺼졌다가 한 알씩 깜빡입니다. **최대 4분** 걸릴 수 있습니다.
- 끝나면 **"감지 완료: N px"** 가 나옵니다. 실패하면 "자동 감지 실패 — 직접 입력을 사용해주세요" 가 나오고 개수는 바뀌지 않습니다.
- 새 제어기와 공장초기화한 제어기는 켜진 뒤 **약 12초 후 자동으로** 한 번 측정합니다.

### 직접 입력

|---|---|---|
| **1** | 총개수 (Length) | 실제 연결된 LED 전체 수 (1 ~ 350). 제어기 한 대가 맡는 상한이며, 더 긴 라인은 제어기를 나눠 **그룹**(최대 10대, 합계 3,500개)으로 연결합니다 |
| **2** | 시작점 (Start) | 앞에서 건너뛸 LED 수 (0 = 처음부터) |

| **4** | 취소 / 저장 | |

> 구간을 나눠 둔 기기에서 LED 개수를 바꾸면 **"구간 나누기 초기화"** 확인이 먼저 나옵니다. 계속하면 구간 설정이 지워집니다.

## 모션인식센서

제어기의 **확장 헤더**(3.3V·GND·TX·RX)에 레이더 모션인식센서 **HLK-LD2402**(또는 LD2412)를 꽂으면 설정 탭에 **모션인식센서** 란이 나타납니다. 센서 TX 를 제어기 RX 에, 센서 RX 를 제어기 TX 에 잇습니다(두 선이 바뀌어 있어도 제어기가 알아서 찾습니다). 센서는 전원이 들어온 뒤 **30~60초** 지나야 보고를 시작합니다. 안 보이면 설정 탭의 **🔍 자동 연결 감지** 를 누르세요.

| 항목 | 설명 |
|---|---|
| **상태** | 인식 / 미인식과 **측정 거리**(cm)를 1초마다 보여 줍니다 |
| **최대 감지 거리** | 이 거리 밖의 사람은 무시합니다 — 1.0~10.0 m, 0.5 m 단위(공장값 8.5 m). 옆의 "≈ 게이트 N" 은 센서 내부 구간(0.7 m) 수입니다 |
| **무인 지연 시간** | 사람이 사라진 뒤 **미인식**으로 바뀌기까지 기다리는 시간(초, 공장값 30) |
| **이동 감도 · 미동 감도** | 움직이는 사람 / 거의 움직이지 않는 사람을 알아보는 문턱(dB). **작을수록 민감**합니다. 슬라이더는 대표값이고, 감지 범위 안 모든 구간에 한꺼번에 적용됩니다 |
| **게이트별 고급 설정 ›** | 구간(게이트 0~15, 0.7 m 마다)별로 이동·미동 문턱을 따로 넣습니다. 흐린 줄은 최대 감지 거리 밖입니다 |
| **자동 문턱 보정** | 센서 앞 공간을 **비운 뒤** 누르면 센서가 약 1분 동안 주변 배경을 재고 문턱을 스스로 정합니다. 진행률이 끝나면 새 값이 화면에 들어옵니다 |
| **모듈** | 센서 펌웨어 버전과 전원 간섭 상태 |
| **적용** | 바꾼 값을 센서에 보냅니다. 값은 **센서 자체에 저장**되어 제어기를 바꿔 꽂아도 유지됩니다 |

> 시퀀스에서 쓰려면 [공통 11장](공통-11-시퀀스) 의 트리거 **디지털 신호 → 모션인식센서 → 인식 / 미인식** 을 고르세요. 같은 그룹의 어느 제어기에 꽂아도 그룹 전체가 반응합니다.
