# 라인조명 6. 고장 신고 전 확인하기

제품이 이상하다고 느껴지면, 구매처에 문의하기 전에 아래 표를 먼저 확인해 주세요. WiFi·앱·그룹처럼 모든 제품에 같은 문제는 [[공통 13. 문제 해결|공통-13-문제-해결]]을 보세요.

> 🔍 **[매뉴얼 검색](https://diyversity-official.github.io/User-Manual-/)** 에 화면에 나온 문구를 그대로 넣어도 찾을 수 있습니다.

---

## 증상으로 찾기

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| LED가 **전혀 안 켜짐** | LED 커넥터가 빠짐 (설정 → 장비가 **Not connected**) | 커넥터를 끝까지 꽂고 전원을 뺐다 꽂으세요 |
| | 전원 보호가 출력을 끊음 (화면 위쪽 🟥 빨간 안내) | 배선 합선·눌림을 확인하고 전원을 뺐다 꽂으세요 → [라인조명 5장](라인조명-05-전원-보호와-경고) |
| | 전원이 꺼짐이거나 밝기가 너무 낮음 | 라이트 탭에서 전원과 밝기를 확인하세요 |
| 갑자기 **어두워짐** | 전류가 많아 밝기를 자동으로 낮춤 (🟧 주황 안내) | 그대로 써도 됩니다. 계속되면 밝기를 낮추거나 LED 길이·전원 용량을 확인하세요 |
| **색이 바뀌지 않음** (흰색만 나옴) | **LINE 12V** 는 흰색 전용 제품 | 밝기로 조절하세요. 설정 → 장비에서 제품 종류를 확인할 수 있습니다 |
| LED **끝부분이 안 켜지거나** 개수가 안 맞음 | LED 개수가 실제와 다름 | 설정 → LED 개수 → **자동 감지** 를 누르세요 → [라인조명 4장](라인조명-04-제어기-설정) |
| LED가 **한 알씩** 켜졌다 꺼지며 이동 | LED 개수를 세는 중 (정상) | 끝날 때까지 기다리세요 (최대 4분) |
| **꺼졌다가 약 3초 뒤** 다시 켜짐 | 전원 쪽 순간 이상을 감지했다가 스스로 복구함 | 1시간 안에 반복되면 꺼진 채로 남으니 배선을 확인하세요 |
| 앱에서 **기기가 안 보임** | 공유기 연결 문제 | [공통 13. 문제 해결](공통-13-문제-해결)을 보세요 |

## 화면 문구로 찾기

라인조명 화면에 뜨는 문구는 공통 문제 해결에 모아 두었습니다.

- 전력 경고 (🟧 인텔리전트 전류 조정, 🟥 과전류 차단, 🟥 이상 동작 감지) → [[전력 경고|공통-13-문제-해결#전력-경고]]
- LED 개수 (자동 측정 중, 자동 감지 실패, 구간 나누기 초기화) → [[LED 개수|공통-13-문제-해결#led-개수]]
- 조명 모습으로 알기 → [[조명 모습으로 알기|공통-13-문제-해결#조명-모습으로-알기]]
