# 24. 다운라이트 소개

**DIYversity 다운라이트 제어기**는 천장 다운라이트 전구를 최대 **6개**까지 연결해 폰으로 켜고, **밝기와 색온도**(따뜻한 빛 ↔ 차가운 빛)를 바꾸고, 전구에서 전구로 흐르는 연출을 넣는 WiFi 제어기입니다.
앱과 기기 화면은 라인조명 제어기와 같습니다. 이 7부에서는 **다운라이트만 다른 부분**을 설명하고, 같은 부분은 앞 장으로 안내합니다.

## 라인조명 제어기와 다른 점

| | 라인조명 제어기 | 다운라이트 제어기 |
|---|---|---|
| 연결하는 것 | LED 스트립(라인) 한 줄 | 다운라이트 전구 최대 6개 (CH1 ~ CH6) |
| 조절할 수 있는 것 | 밝기 · 색상 · 연출 (제품에 따라 흰색·색온도) | **밝기 · 색온도** · 연출 (색상은 없습니다) |
| 연결 확인 | LED 개수 **자동 감지** | **전구 재탐색** — 어느 채널에 전구가 꽂혔는지 찾습니다 → [26장](26-전구-재탐색과-배치) |
| 연출이 흐르는 단위 | LED 한 알(px) | 전구 **묶음** (함께 켜지는 전구들) |
| 전원 | LED 종류에 맞는 5V · 12V | **24V** 입력 — 입력 전류를 실시간으로 잽니다 → [29장](29-다운라이트-전원-보호) |
| 설정 → 장비 표시 | `LINE … · 자동 인식` | `… · 보드 확인` |

## 할 수 있는 것

| 기능 | 설명 | 안내 |
|---|---|---|
| 폰으로 제어 | 켜기/끄기, 밝기, 색온도 2700K ~ 6500K | [28장](28-다운라이트-밝기-색온도-연출) |
| 전구 재탐색과 배치 | 연결된 전구를 찾고, 천장 배치 그림과 묶음, 연출 순서를 정합니다 | [26장](26-전구-재탐색과-배치) |
| 전구 간격 · 상세 위치 | 전구 사이 거리를 연출에 반영합니다 | [27장](27-전구-간격과-상세-위치) |
| 연출 | 숨쉬기·촛불 같은 밝기 변화, 전구에서 전구로 넘어가는 흐름 | [28장](28-다운라이트-밝기-색온도-연출) |
| 루틴 · 시퀀스 · 그룹 | 라인조명 제어기와 같습니다 | [8장](08-루틴) · [13장](13-시퀀스) · [11장](11-그룹-연결) |
| 전원 보호 | 입력 전류가 한계를 넘으면 곧바로 끊고 다시 켭니다 | [29장](29-다운라이트-전원-보호) |
| 무선 업데이트 | 앱에서 최신 펌웨어로 | [5장](05-펌웨어-업데이트) |

## 사양

| 항목 | 값 |
|---|---|
| 입력 전원 | 24V ⬜ 확인 필요: 허용 범위, 권장 어댑터 용량 |
| 출력 채널 | 6채널 (CH1 ~ CH6), 채널마다 따뜻한 빛(WW)·차가운 빛(CW) |
| 맞는 전구 | ⬜ 확인 필요: 전구 규격(전압·전력·커넥터) |
| 색온도 | 2700K(전구색) ~ 6500K(주광색) |
| 전류 한계 | 3,500 mA (24V 입력 기준) |
| 무선 | 2.4GHz WiFi |
| 크기 · 무게 | ⬜ 확인 필요 |
| 사용 환경 | ⬜ 확인 필요: 온도, 실내 전용 여부 |

## 준비물

- DIYversity 다운라이트 제어기 + 다운라이트 전구(최대 6개) + 24V 전원 어댑터
- 스마트폰 (안드로이드 또는 아이폰)
- (권장) **2.4GHz WiFi 공유기**
