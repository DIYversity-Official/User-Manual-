# 매뉴얼 재구성 초안 — 공통 · 라인조명 · 다운라이트

이 폴더는 위키에 올리기 전 **검토용 초안**입니다. 위키는 PR을 받을 수 없어 여기서 검토한 뒤, 승인되면 이 폴더의 `.md` 파일을 위키에 같은 이름으로 올리고(그림은 `images/` 아래 같은 경로) 이 폴더는 지웁니다.

## 구조

- 위키는 하나로 두고 **공통**(모든 제품에 같은 앱·연결) / **라인조명** / **다운라이트** 섹션으로 나눴습니다.
- 페이지 이름은 `섹션-번호-제목` 입니다(예: `공통-02-공유기-WiFi-연결`). 제목도 `공통 2. …` 처럼 섹션 이름이 붙습니다.
- 이전/다음 링크는 같은 섹션 안에서만 이어집니다.
- **새 제품**은 `제품이름-01-…` 페이지들을 만들고, 첫 화면(`DIYversity-메뉴얼.md`, `Home.md`)의 표와 `_Sidebar.md` 에 섹션 하나만 더하면 됩니다.
- 앱과 기기 화면이 여는 첫 화면 주소(`DIYversity-메뉴얼`)는 그대로입니다.
- 옛 페이지 주소(`02-AP-모드로-접속하기` 등)는 새 페이지로 안내하는 짧은 페이지로 남겨, 예전 링크와 북마크가 끊기지 않게 했습니다. 이 안내 페이지는 검색 목록에서 빠집니다(`build_index.py`).
- 본문 내용은 바꾸지 않았습니다. 장 번호·링크·제목·이전/다음 줄만 새 구조에 맞췄고, 공통 공장초기화·문제 해결 첫머리에 다운라이트 안내 한 줄을 더했습니다.

## 다운라이트 초안

- 화면 문구는 다운라이트 펌웨어 v3.0.3 에 든 기기 화면 문구를 그대로 옮겼습니다.
- 확인하지 못한 사양·사진은 **"기입 예정"** 으로, 더 확인할 문장은 `<!-- 검토 필요 -->` 주석으로 남겼습니다.
- 그림: `images/dl-product/topology.svg`(설치 구성), `images/dl-layout/layout-examples.svg`(배치·묶음 예시). 앱 화면 캡처는 `images/dl-layout/`, `images/dl-gap/`, `images/dl-light/`, `images/dl-power/` 에 들어갑니다.
