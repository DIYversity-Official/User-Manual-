# 목차 맞추기 초안 — 라인조명 · 다운라이트 같은 뼈대

이 폴더는 위키에 올리기 전 **검토용 초안**입니다. **바뀌거나 새로 생기는 위키 페이지만** 들어 있습니다(그림은 바뀌지 않음). 승인되면 위키에 같은 이름으로 덮어쓰고 이 폴더는 지웁니다.

## 바뀌는 점

1. **두 제품의 목차를 같은 7장 뼈대로 맞췄습니다.**

   | 장 | 라인조명 | 다운라이트 |
   |---|---|---|
   | 1 | 제품 알아보기 (제품 소개 + 구성품 합침) | 제품 알아보기 |
   | 2 | 설치와 연결 **(새로)** | 설치와 연결 |
   | 3 | 라이트 — 밝기 · 연출 · 색상 | 라이트 — 밝기 · 색온도 · 연출 |
   | 4 | 제어기 설정 | 제어기 설정 (전구 재탐색·배치 + 간격·상세 위치를 합침) |
   | 5 | 전원 보호와 경고 | 전원 보호와 경고 |
   | 6 | 고장 신고 전 확인하기 **(새로)** | 고장 신고 전 확인하기 |
   | 7 | 제품 규격 **(새로)** | 제품 규격 |
   | 8~11 | 퀵 가이드 4개 | — |

   1장 **제품 알아보기**의 절 순서도 같습니다: 제품의 특징 → 제품의 구성 → 각 부분의 이름과 기능 → 버튼 동작에 따른 기능 → LED(전구)가 이렇게 보이면 → 할 수 있는 것 → 준비물 → 제품별 주의 → 처음 설치 순서.

2. **안전 주의를 공통으로 옮겼습니다.** `안전을-위해-주의하기` 한 페이지(공통 섹션 맨 앞)를 두 제품이 함께 씁니다. 제품마다 다른 항목(어댑터 전압, 출력 정격, 전구 재탐색 등)만 각 제품 1장의 **제품별 주의** 에 짧게 남겼습니다.

3. 첫 화면에 **제품별 목차** 표(같은 번호 = 같은 내용)를 넣고, 사이드바도 같은 순서로 맞췄습니다.

4. 옛 주소(`라인조명-02-라이트`, `다운라이트-01-안전-주의` 등)는 새 페이지로 안내하는 페이지로 바뀌어 링크가 끊기지 않습니다. 예전 `02-…`~`23-…` 안내 페이지도 새 주소를 바로 가리키게 고쳤습니다.

5. 위키 표 안의 `[[이름|페이지]]` 링크는 `|` 때문에 표가 깨지므로 일반 링크 `[이름](페이지)` 로 바꿨습니다.

새 장(라인조명 2·6·7)의 확인 못 한 값은 **기입 예정** 으로 두었습니다.
