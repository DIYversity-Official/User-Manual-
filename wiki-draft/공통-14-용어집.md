# 공통 14. 용어집

매뉴얼과 앱·제어기 화면에 나오는 말을 가나다순으로 정리했습니다.

| 용어 | 뜻 |
|---|---|
| **AP 모드** | 제어기가 스스로 WiFi(`DIYversity-…`, 비밀번호 `dv112233`)를 만드는 상태입니다. 새 제어기나 공장초기화한 제어기는 이 상태로 켜집니다. → [공통 1장](공통-01-AP-모드로-접속하기) |
| **CCT** | 따뜻한 흰색과 차가운 흰색 LED를 섞어 **색온도**를 바꿀 수 있는 제품입니다 (LINE 12V CCT). |
| **OTA** | 선 연결 없이 앱에서 무선으로 펌웨어를 업데이트하는 것입니다. → [공통 4장](공통-04-펌웨어-업데이트) |
| **px (픽셀)** | LED 한 알입니다. "총 160 px" 는 LED 160개가 연결되어 있다는 뜻입니다. |
| **구간 나누기** | LED 라인 한 줄을 여러 **조각**으로 잘라, 그룹 안에서 서로 다른 위치에 배치하는 기능입니다. |
| **그룹** | 함께 움직이도록 묶은 제어기들입니다. 마스터 1대 + 슬레이브 여러 대로 이루어집니다. → [공통 9장](공통-09-그룹-연결) |
| **그룹연결 마법사** | 질문에 답하면 그룹과 시퀀스를 자동으로 만들어 주는 기능입니다. → [공통 10장](공통-10-그룹연결-마법사) |
| **딜레이** | "함께 재생" 모드에서 기기마다 연출 시작을 늦추는 시간입니다. |
| **라인** | 제어기 한 대에 연결된 LED 스트립 한 줄입니다. |
| **루틴** | 여러 조명의 켜짐·밝기를 저장해 버튼 하나로 되돌리는 앱 기능입니다. 폰에만 저장됩니다. → [공통 7장](공통-07-루틴) |
| **마스터** | 그룹의 기준 제어기입니다. 그룹 설정·시퀀스·업데이트는 마스터 화면에서 합니다. 그룹에 속하지 않은 제어기도 설정 탭의 역할에는 "마스터"로 표시됩니다(혼자 쓰는 상태를 "단독 모드"라고도 합니다). |
| **단회성 연출** | 한 번 재생하고 끝나는 연출입니다 (DIY 웰컴, 서서히 밝아짐 등). 시퀀스에서 끝나면 자동으로 다음 단계로 넘어갑니다. |
| **슬레이브** | 마스터를 따라 같은 순간에 켜지고 바뀌는 제어기입니다. 앱 홈에는 따로 나오지 않습니다. |
| **시퀀스** | "전원이 켜지면 → 웰컴 연출 → 흰색 유지" 처럼 조건에 따라 자동으로 실행되는 연출 순서입니다. → [공통 11장](공통-11-시퀀스) |
| **연결 모드** | 그룹이 움직이는 방식입니다. **하나로 잇기**(여러 줄이 한 줄처럼 이어짐) / **함께 재생**(모두 같은 연출을 동시에). |
| **연출** | 무지개·흐름·반짝임 같은 조명 효과입니다. |
| **자동 감지 (LED 개수)** | 제어기가 연결된 LED 개수를 스스로 측정하는 기능입니다. → [라인조명 3장](라인조명-03-제어기-설정) |
| **전원 보호** | 전류가 너무 많이 흐르면 밝기를 자동으로 낮추고, 위험하면 출력을 끊는 기능입니다. → [라인조명 4장](라인조명-04-전원-보호와-경고) |
| **정밀 동기** | 그룹의 제어기들이 같은 시각에 맞춰 움직이고 있다는 상태 표시입니다. |
| **트리거** | 스위치·센서 같은 외부 신호입니다. 시퀀스를 시작하는 조건으로 씁니다. |
| **팔레트** | 연출에 쓰이는 색 조합입니다. |
| **펌웨어** | 제어기 안에서 동작하는 프로그램입니다. 설정 탭에서 버전(예: `v1.0.25`)을 확인합니다. |
| **혼자** | 그룹에 속한 채로 그 기기만 동기에서 빠져 따로 동작하게 하는 설정입니다. 다시 누르면 합류합니다. |
