# 라인조명 1. 제품 알아보기

**DIYversity 라인조명 제어기**는 LED 스트립(라인)을 폰으로 켜고, 색·연출을 바꾸고, 자동으로 동작하게 만드는 WiFi 제어기입니다.
한 대로도 쓸 수 있고, 여러 대를 **그룹**으로 묶으면 떨어져 있는 조명들이 **한 줄처럼 이어져** 같은 순간에 움직입니다.

![설치 구성 3가지](images/01-intro/topology.svg)

---

## 제품의 특징

- 연결된 LED 라인의 **종류와 길이를 스스로 알아봅니다.**
- 밝기 · 색상 · 100여 가지 연출, CCT 제품은 흰색 밝기와 색온도까지 조절합니다.
- 여러 대를 그룹으로 묶으면 **한 줄처럼 이어지거나 함께 재생**됩니다.
- **전류계**로 LED 전류를 재서, 많이 흐르면 밝기를 낮추고 위험하면 출력을 끊습니다.
- 루틴·시퀀스·무선 업데이트 같은 앱 기능을 씁니다.

## 제품 종류

제어기는 연결된 LED 라인의 종류를 **스스로 알아봅니다.** 기기 화면 **설정 → 장비** 에 표시됩니다.

| 장비 이름 | LED | 조절할 수 있는 것 |
|---|---|---|
| **LINE 5V** | 5V 컬러 LED | 밝기 · 색상 · 연출 |
| **LINE 12V** | 12V 흰색 LED | 밝기 · 연출 (흰색 전용 — 색상은 바뀌지 않습니다) |
| **LINE 12V CCT** | 12V 컬러 + 흰색(따뜻한·차가운) LED | 밝기 · 색상 · **흰색 밝기 · 색온도** · 연출 |

| ② | LED 출력 커넥터 | LED 라인을 연결합니다. 정격 **5A** → [라인조명 5장](라인조명-05-전원-보호와-경고) |

## 버튼 동작에 따른 기능

| 버튼 | 동작 | 기능 |
|---|---|---|
| 초기화 버튼 | 전원이 켜진 상태에서 **5초 이상** 누르기 | 공장초기화 — LED 전체가 빨간색으로 바뀌면 손을 뗍니다 → [공통 12장](공통-12-공장초기화) |
| 초기화 버튼 | 전원을 꽂을 때부터 누르고 있기 | 제어기가 켜지지 않습니다 — 버튼을 놓고 전원을 다시 꽂으세요 |

## LED가 이렇게 보이면

| LED 모습 | 뜻 |
|---|---|
| LED가 **한 알씩** 켜졌다 꺼지며 이동 | LED 개수를 세는 중 (설치 직후나 **자동 감지**) → [라인조명 4장](라인조명-04-제어기-설정) |
| **점점 어두워졌다가** 서서히 밝아짐 | 전류가 많아 밝기를 자동으로 조절함 (정상 보호 동작) → [라인조명 5장](라인조명-05-전원-보호와-경고) |
| **꺼진 채로** 켜지지 않고, 기기 화면에 🟥 빨간 안내 | 과전류 차단 또는 이상 동작 감지 → [라인조명 6장](라인조명-06-고장-신고-전-확인) |
| **전체가 흰색으로** 빠르게 깜빡임 | 그룹연결 마법사에서 이 제어기를 선택함 (확인용) |
| **빨간색** 으로 잠깐 켜진 뒤 다시 켜짐 | 공장초기화가 끝남 |

## 준비물

- DIYversity 라인조명 제어기 + LED 라인 + 전원 어댑터
- 스마트폰 (안드로이드 또는 아이폰)
- (권장) **2.4GHz WiFi 공유기** — 없어도 제어기 자체 WiFi로 쓸 수 있습니다

> 사양(크기·전원·무선)은 [라인조명 7장 제품 규격](라인조명-07-제품-규격)에 있습니다.

## 제품별 주의

모든 제품에 해당하는 내용은 [[안전을 위해 주의하기|안전을-위해-주의하기]]를 먼저 읽어 주세요. 라인조명은 아래도 지켜 주세요.

- LED 종류에 맞는 **5V 또는 12V** 어댑터를 쓰세요. 5V LED에 12V를 넣으면 LED가 망가집니다.
- 출력 커넥터 정격은 **5A** 입니다. 더 긴 LED는 제어기를 나눠 그룹으로 연결하세요.
- LED 라인을 감긴 채로 오래 켜 두지 마세요. 열이 쌓일 수 있습니다.
