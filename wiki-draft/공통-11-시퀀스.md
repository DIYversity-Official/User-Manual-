# 공통 11. 시퀀스 — 자동으로 실행되는 연출

**시퀀스**는 "언제(트리거)" 와 "무엇을 어떤 순서로(스텝)" 를 정해 두면 제어기가 알아서 실행하는 연출 순서입니다.
예: *전원을 켜면 → 웰컴 모션 → 흰색으로 계속 켜 두기* / *평일 오전 8:30 → 흰색 5초 → 3초 대기 → 반복*

시퀀스는 그룹의 **마스터** 기기 화면 → **🎬 시퀀스** 탭에서 만들며, 그룹 전체가 함께 실행합니다.

### ① 트리거 고르기

| 트리거 | 실행 시점 |
|---|---|
| **전원 온** | 제어기에 **전원이 들어올 때** (벽 스위치로 켜는 설치에 적합). 한 개만 만들 수 있습니다 |
| **트리거** | 출력 커넥터 신호가 **켜질 때(HIGH)** 또는 **꺼질 때(LOW)** — 최대 24V |
| **디지털 신호** | 연결된 센서의 신호 — **🔍 자동 연결 감지** 로 찾습니다. **모션인식센서**(레이더 LD2402·LD2412)를 꽂았으면 목록에 "모션인식센서 (LD2402)" 로 나타나고 **인식**(사람이 나타날 때) / **미인식**(무인 지연 시간이 지나 사람이 없다고 판단할 때) 중 하나를 트리거로 고릅니다. 센서 설정은 [라인조명 4장 모션인식센서](라인조명-04-제어기-설정#모션인식센서) |
| **⏰ 스케줄** | 정해 둔 **요일·시각** — 인터넷 시간으로 맞춥니다(공유기 연결 필요) |

- **단회성 연출**(DIY 웰컴 등)은 효과가 끝나면 자동으로 다음 스텝으로 넘어갑니다.
- 반복형 연출은 **재생 시간**이 지나면 다음 스텝으로 넘어갑니다.
- **마지막 스텝**에 반복이 없으면 시간과 관계없이 그 상태가 **계속 유지**됩니다 (스텝에 "유지" 표시).

- **앱에서 켤 때 이 시퀀스 실행** — 앱 홈·기기 화면의 전원 버튼으로 켤 때 이 연출로 켜집니다.

## 이런 안내가 나오면

| 안내 | 뜻 |
|---|---|
| 스텝이 없습니다 — 연출/대기를 추가하세요 | 실행 순서가 비어 있습니다 |
| '전원 온' 시퀀스는 하나만 등록할 수 있습니다 | 기존 전원 온 시퀀스를 수정하거나 지우세요 |
| …같은 조건이 함께 켜지면 효과가 충돌합니다 | 같은 트리거·조건의 켜진 시퀀스가 이미 있습니다. 하나를 끄세요 |
| 시퀀스 저장 용량(10KB)을 넘습니다 — 스텝을 줄이거나 다른 시퀀스를 삭제하세요 | 시퀀스 전체의 저장 용량이 찼습니다. 스텝을 줄이거나 안 쓰는 시퀀스를 삭제하세요 |
| 시퀀스는 최대 16개입니다 — 안 쓰는 시퀀스를 삭제하세요 | 시퀀스 개수 한도입니다 |
| 스텝은 시퀀스마다 최대 32개입니다 | 한 시퀀스의 스텝 한도입니다 |

> 시퀀스 목록은 제어기에 한 묶음으로 저장되며 **저장 용량은 10KB** 입니다(연출 스텝 약 30개 분량, 대기 스텝은 거의 차지하지 않습니다). 시퀀스는 최대 **16개**, 시퀀스마다 스텝 **32개**까지지만 그 전에 용량이 먼저 찰 수 있습니다. 시퀀스 화면의 **저장 용량** 표시가 10KB 를 넘으면 저장되지 않으니 스텝을 줄이거나 안 쓰는 시퀀스를 삭제하세요. 공장초기화해도 시퀀스는 지워지지 않습니다.
