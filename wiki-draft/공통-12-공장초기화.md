# 공통 12. 공장초기화

제어기를 **처음 산 상태**로 되돌립니다. 공유기를 바꿀 때, 다른 곳에 옮겨 설치할 때, 설정이 꼬여 처음부터 다시 하고 싶을 때 사용하세요.

![초기화 버튼으로 공장초기화](images/16-reset/factory-reset.svg)

> 💡 아래 화면과 LED 색은 **라인조명** 제어기 기준입니다. 다운라이트는 [[다운라이트 6. 고장 신고 전 확인하기|다운라이트-06-고장-신고-전-확인#공장초기화]]도 함께 보세요.

---

## 방법

1. 제어기 **전원이 켜진 상태**인지 확인합니다.
2. 제어기의 **초기화 버튼**을 **5초 이상** 꾹 누릅니다.
3. LED 라인 전체가 **빨간색**으로 바뀌면 손을 뗍니다 → 잠시 뒤 자동으로 다시 켜집니다.
   - **주황색**으로 바뀌면 일부가 덜 지워진 것입니다. 한 번 더 5초 누르세요.
4. [[공통 1. AP 모드로 처음 접속하기|공통-01-AP-모드로-접속하기]]부터 다시 설치합니다.

> ⚠️ **전원을 꽂는 순간부터 버튼을 누르고 있으면 제어기가 켜지지 않습니다.**
> 켜지지 않았다면 전원을 뺀 뒤, 버튼을 누르지 않은 채로 다시 꽂으세요.

## 무엇이 지워지나요?

| 지워지는 것 | 남는 것 |
|---|---|
| 공유기 WiFi 연결 정보 | 펌웨어 버전 |
| 그룹 (마스터·슬레이브 관계, 그룹 이름) | **시퀀스** — 필요 없으면 시퀀스 탭에서 직접 지우세요 |
| LED 개수, 구간 나누기 등 제어기 설정 | |
| 저장된 연출 설정 | |

## 초기화 직후의 제어기

- 폰 WiFi 목록에 **`DIYversity-` + 12자리** WiFi가 다시 나타납니다 (비밀번호 `dv112233`).
- 접속하면 **"새 제어기가 준비되었습니다"** 첫 화면이 다시 나옵니다.
- 켜지고 약 **12초 뒤 LED 개수를 자동으로 다시 셉니다.** LED가 한 알씩 깜빡이는 것은 정상입니다.
- 그룹에 속해 있던 제어기라면, 마스터 화면의 그룹 목록에서는 **연결 끊김**으로 보입니다. → [[공통 9장|공통-09-그룹-연결]]
  - 초기화한 제어기를 공유기에 다시 연결하면 **원래 마스터가 곧바로 다시 슬레이브로 묶을 수 있습니다.** 이때 앱 홈에는 따로 나타나지 않습니다.
  - 그 제어기를 따로 쓰려면 마스터 화면 **🔗 그룹 연결 → 구성** 목록에서 그 기기를 **✕** 로 먼저 지우세요.

> 💡 앱 목록의 기기는 초기화해도 그대로 남아 있습니다(연결 안 됨 상태). 다시 설치하면 같은 타일로 돌아옵니다.
