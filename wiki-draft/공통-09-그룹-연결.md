# 공통 9. 그룹 연결 — 여러 대를 한 줄처럼

여러 제어기를 **그룹**으로 묶으면 떨어진 조명들이 같은 순간에 켜지고, 흐르는 연출이 기기 경계를 넘어 이어집니다.
그룹 설정은 모두 **기준 제어기(마스터)** 의 기기 화면 → **🔗 그룹 연결** 탭에서 합니다.

![연결 모드 2가지](images/11-group/connection-mode.svg)

> 슬레이브 화면을 열면 "이 기기는 슬레이브입니다 — 그룹 구성·마법사는 마스터에서 관리합니다" 가 나옵니다. **마스터로 이동 ›** 을 누르세요.

## 새 기기를 그룹에 추가하기

- 그룹에 이미 2대 이상 있으면 **"추가하는 동안 그룹 연결이 20~30초 잠시 끊깁니다"** 확인이 먼저 나옵니다.
- 검색에 나오지 않는 기기: 이미 다른 그룹에 속했거나 이름을 지어 쓰던 기기입니다. [[공장초기화|공통-12-공장초기화]] 후 다시 검색하세요.
- 새 기기와 마스터가 너무 멀면 "기기 AP에 접속하지 못했습니다(거리·전파 확인)" 가 나옵니다. 가까이에서 추가한 뒤 설치하세요.
- 그룹은 **최대 9대**(마스터 1 + 슬레이브 8)까지 묶을 수 있습니다.

## 기기별 버튼

| 버튼 | 하는 일 |
|---|---|
| **≡** (끌기) | 위아래로 끌어 **순서**를 바꿉니다 — 실제로 LED가 이어진 순서와 같게 맞추세요 |
| **⇄** | 그 기기의 흐름 **방향을 반대로** 합니다 (라인을 거꾸로 설치했을 때) |
| **딜레이** | (함께 재생) 그 기기의 연출 시작을 늦춥니다 |
| **혼자** | 그 기기만 그룹 동기에서 빠져 따로 동작합니다 (다시 누르면 합류) |
| **⚙** | 그 기기의 설정 탭으로 이동 → [라인조명 4장](라인조명-04-제어기-설정) |
| **✕** | 그룹에서 제거 (한 번 더 눌러 **확인**) |
