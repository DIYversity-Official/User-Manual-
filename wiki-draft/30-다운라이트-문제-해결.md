# 30. 다운라이트 문제 해결

다운라이트에서만 생기는 증상과 화면 문구를 정리했습니다. WiFi·앱·그룹처럼 라인조명과 같은 문제는 [17장 문제 해결](17-문제-해결)을 보세요.

> 🔍 **[매뉴얼 검색](https://diyversity-official.github.io/User-Manual-/)** 에 화면에 나온 문구를 그대로 넣어도 찾을 수 있습니다.

---

## 증상으로 찾기

| 증상 | 원인과 할 일 |
|---|---|
| 전구 하나가 **켜지지 않음** | 재탐색 결과에서 그 채널을 확인하세요. **제외 · 쇼트** 면 배선 합선, **맞지 않는 전구** 면 전구를 바꾸세요. 아무 표시도 없으면 커넥터가 빠졌는지 확인하고 **다시 찾기** 를 누르세요 → [26장](26-전구-재탐색과-배치) |
| 전구 하나만 **색온도가 바뀌지 않음** | 전구의 두 줄 중 한 줄만 연결되었습니다(**… 빛만**). 배선을 확인하세요 |
| 연출이 **천장 순서와 다르게** 흐름 | 배치 화면에서 **전구 확인** 으로 번호와 실제 전구를 맞추고 **자리 바꾸기** · **순서 매기기** 로 고치세요 → [26장](26-전구-재탐색과-배치) |
| **흐름 연출이 목록에 없음** | 묶음이 1개(**한 묶음**)이거나 전구가 1개입니다. 묶음을 **1개씩** 등으로 바꾸세요 |
| **전구 간격** 줄이 안 보임 | 배치를 아직 저장하지 않았거나 묶음이 1개입니다 |
| 모든 전구가 **잠깐 꺼졌다 다시 켜짐** | 입력 전류가 한계를 넘어 보호가 동작했습니다 → [29장](29-다운라이트-전원-보호) |
| 모든 전구가 **꺼진 채 켜지지 않음** | 설정 → 전력의 **보호 상태** 를 확인하세요 → [29장](29-다운라이트-전원-보호) |
| 전구가 **모두 켜졌다가 하나씩 꺼짐** | 재탐색 중입니다. 약 5초 기다리세요 |

## 화면 문구로 찾기

| 화면 문구 | 뜻 | 할 일 |
|---|---|---|
| **연결된 전구가 없습니다** | 재탐색에서 전구를 하나도 찾지 못했습니다 | 전구 연결과 24V 전원을 확인하고 다시 찾으세요 |
| **한쪽 스트링만 연결된 전구 N개 — 그 전구는 색온도가 바뀌지 않습니다(배선을 확인하세요)** | 전구 두 줄 중 한 줄만 연결됨 | 배선 확인 |
| **CHn: 이 보드에 맞지 않는 전구(전압이 낮아 밝기 조절 불가) — 켜지 않습니다** | 다른 규격의 전구 | 맞는 전구로 교체 |
| **재탐색이 끝나지 않았습니다** / **폴트·입력 전원을 확인한 뒤 다시 찾아 주세요(진행 중에 끊겼거나 응답이 없습니다)** | 재탐색 중 전원 보호가 동작했거나 응답이 끊겼습니다 | 배선·전원 확인 후 다시 찾기 → [29장](29-다운라이트-전원-보호) |
| **이전 감지 결과로 조명을 다시 켰습니다 — 폴트·입력 전원을 확인한 뒤 다시 찾아 주세요** | 재탐색이 실패해 예전 결과로 켰습니다 | 위와 같음 |
| **전구 정보가 맞지 않습니다 — 다시 찾아 주세요** | 배치를 고르는 동안 전구 연결이 바뀜 | 재탐색부터 다시 |
| **저장했지만 기기에 적용되지 않았습니다 — 다시 찾은 뒤 골라 주세요** | 배치가 기기에 반영되지 않음 | 재탐색부터 다시 |
| **배치를 먼저 정해 주세요** | 간격은 배치를 저장한 뒤에 정할 수 있습니다 | [26장](26-전구-재탐색과-배치) |
| **다운라이트 정보를 읽지 못했습니다** / **배치 화면을 불러오지 못했습니다** | 기기와 통신이 끊겼습니다 | 같은 공유기에 있는지 확인하고 화면을 다시 여세요 |
| **이 기기의 IP를 아직 몰라 설정할 수 없습니다** | 그룹의 다른 기기 주소를 아직 모릅니다 | 잠시 뒤 다시 시도하거나 그 기기에 직접 접속하세요 |

## 공장초기화

라인조명 제어기와 같이 **초기화 버튼을 5초 이상** 눌러 처음 상태로 되돌립니다. → [16장](16-공장초기화)
