# 다운라이트 7. 전원 보호

다운라이트 제어기에는 **전류계**가 들어 있어 **24V 입력 전류**를 실시간으로 잽니다.
전류가 한계를 넘으면 보호 회로가 **곧바로 출력을 끊고 다시 켭니다.** 사용자가 켜고 끌 설정은 없습니다 — 항상 자동으로 동작합니다.

> 라인조명 제어기의 보호 방식(밝기 자동 제한 등)은 [라인조명 4장](라인조명-04-전원-보호와-경고)을 보세요. 다운라이트는 아래 방식으로 동작합니다.

---

## 전류 보기

기기 화면 → **⚙️ 설정 → 전력**

- 막대와 숫자로 지금 **24V 입력 전류**(mA)를 보여 줍니다.
- 오른쪽의 **한계 3,500 mA** 가 보호가 동작하는 기준입니다.

*(화면 캡처 기입 예정)*

<!-- 화면 캡처 (images/dl-power/01-power.png) -->

## 보호가 동작하는 순서

1. 입력 전류가 한계를 넘으면 **즉시 출력을 끊습니다.**
2. 잠시 뒤 **스스로 다시 켭니다**(과전류 재투입 대기).
3. **1분 안에 3번** 일어나면 더 이상 다시 켜지 않고 **멈춥니다.** 이때는 제어기를 다시 시작해야 합니다.

## 보호 상태 표시

보호가 동작 중이면 전력 줄 아래에 **⚠ 보호 상태** 가 함께 나옵니다.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| **과전류 재투입 대기** | 한계를 넘어 출력을 끊었고, 곧 다시 켭니다 | 계속 반복되면 아래 "멈췄을 때" 를 따르세요 |
| **멈춤(재시작 필요)** | 1분 안에 3번 끊겨 출력을 멈췄습니다 | 아래 "멈췄을 때" 를 따르세요 |
| **입력 전압 낮음** | 24V 전원이 충분하지 않습니다 | 어댑터 전압·용량과 전원 배선을 확인하세요 |
| **전류 센서 이상** | 제어기 안 전류계를 읽지 못했습니다 | 전원을 다시 넣어 보고, 계속되면 구매처에 문의하세요 |
| **보드 불일치** | 이 보드와 맞지 않는 펌웨어가 들어 있어 출력을 막았습니다 | 구매처에 문의하세요 |

## 멈췄을 때

1. 전구 배선에 **합선이나 눌림**이 없는지 확인합니다.
2. **맞는 전구**인지, 전구 수에 비해 **어댑터 용량**이 충분한지 확인합니다. (권장 어댑터 용량: *기입 예정*)
3. 제어기 **전원을 뺐다가 다시 꽂습니다.**
4. **⚙️ 설정 → 전구 재탐색 및 배치** 에서 **재탐색** 해 채널 표시를 확인합니다. 쇼트·맞지 않는 전구가 있는 채널은 제어기가 알아서 켜지 않습니다. → [다운라이트 4장](다운라이트-04-전구-재탐색과-배치)

> 같은 증상이 반복되면 사용을 멈추고 구매처에 문의하세요.
