# 공통 13. 문제 해결

문제가 생겼을 때 두 가지로 찾을 수 있습니다.

- **[증상으로 찾기](#증상으로-찾기)** — "앱에 기기가 안 나와요" 처럼 겪고 있는 상황으로 찾습니다.
- **[화면 문구로 찾기](#화면-문구로-찾기)** — 앱이나 기기 화면에 뜬 안내·경고 문구로 찾습니다.

> 💡 **[🔍 매뉴얼 검색](https://diyversity-official.github.io/User-Manual-/)** 에 화면에 뜬 문구의 앞 몇 낱말을 넣으면 해당 줄을 바로 찾을 수 있습니다.
> 표가 화면보다 넓으면 표를 **옆으로 밀어** 보세요.

> 💡 다운라이트에서만 생기는 증상(전구가 안 켜짐, 색온도가 안 바뀜, 배치 등)은 [[다운라이트 8. 고장 신고 전 확인하기|다운라이트-08-고장-신고-전-확인]]을 보세요.

## 증상으로 찾기

### 연결

| 증상 | 확인하고 해결하기 |
|:---|:---|
| **폰 WiFi 목록에 `DIYversity-…` 가 없어요** | ① 제어기 전원을 확인하고 잠시 기다리세요. ② 이미 공유기에 연결해 그룹에 들어간 제어기(슬레이브)는 자체 WiFi를 켜지 않습니다. ③ 처음 상태로 설치하려면 [공장초기화](공통-12-공장초기화) 후 다시 찾으세요. |
| **제어기 WiFi 비밀번호를 모르겠어요** | 모든 제어기의 WiFi 비밀번호는 **`dv112233`** 입니다. |
| **"네트워크에 로그인하세요" 를 눌러도 화면이 안 떠요** | 인터넷 앱 주소창에 **`http://4.3.2.1`** 을 입력하세요. 크롬이 "보안 연결을 지원하지 않습니다" 라고 하면 **사이트로 이동**, 화면이 비어 있으면 폰의 **모바일 데이터를 끄고** 다시 여세요. → [공통 1장](공통-01-AP-모드로-접속하기) |
| **공유기가 목록에 안 보여요** | 제어기는 **2.4GHz WiFi만** 지원합니다. `5G` 가 붙은 이름은 나오지 않습니다. 공유기 가까이에서 다시 검색하세요. |
| **공유기 연결 후 앱에 기기가 안 나와요** | ① 폰이 **같은 공유기 WiFi** 에 연결되어 있는지 ② 비밀번호를 정확히 넣었는지 ③ 게스트 WiFi·AP 격리가 꺼져 있는지 확인하세요. 아이폰은 **로컬 네트워크 허용**이 필요합니다. → [공통 3장](공통-03-앱으로-기기-찾기) |
| **아침에 앱이 제어기를 못 찾아요** | 공유기 보안이 예전 방식이면, 새벽에 공유기가 기기를 잠깐 내보낸 뒤 제어기가 제때 다시 들어오지 못했을 수 있어요. 공유기 보안 방식을 **WPA2-PSK (AES)** 로 바꿔 주세요. 급할 때는 제어기 전원을 껐다 켜면 바로 다시 연결돼요. → [공통 2장 공유기 보안 방식 맞추기](공통-02-공유기-WiFi-연결#공유기-보안-방식-맞추기) |
| **다른 공유기로 바꾸고 싶어요** &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | [공장초기화](공통-12-공장초기화) 후 [공통 1장](공통-01-AP-모드로-접속하기)부터 다시 설치하세요. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |

### 앱

| 증상 | 확인하고 해결하기 |
|:---|:---|
| **홈 타일 스위치를 눌러도 조명이 그대로예요** | 앱과 제어기의 연결이 끊긴 상태일 수 있습니다. 홈 화면에는 끊김 표시가 따로 없어 꺼진 기기처럼 보입니다. 제어기 전원과 공유기를 확인하고, 앱을 닫았다가 다시 여세요. |
| **삭제한 기기가 다시 나타나요** | 정상입니다. 삭제는 앱 목록에서만 지우고, 켜져 있는 제어기는 다시 찾아집니다. 안 보이게 하려면 **숨기기**를 쓰세요. → [공통 6장](공통-06-기기-관리) |
| **그룹에 넣은 제어기가 홈에서 사라졌어요** | 정상입니다. 그룹은 **마스터 타일 하나**로 함께 제어됩니다. |
| **다른 폰에 루틴이 없어요** &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | 루틴은 만든 폰에만 저장됩니다. 다른 폰에서 새로 만드세요. → [공통 7장](공통-07-루틴) &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |

### 조명

| 증상 | 확인하고 해결하기 |
|:---|:---|
| **갑자기 어두워지거나 꺼졌어요** | 전원 보호가 동작했을 수 있습니다. 기기 화면 위쪽의 **빨간색/주황색 안내**를 확인하세요. → [라인조명 4장](라인조명-04-전원-보호와-경고) |
| **LED가 전혀 안 켜져요** | ① 기기 화면 **설정** 의 장비가 **Not connected** 로 나오면 LED 커넥터를 끝까지 꽂고 전원을 뺐다 꽂으세요. ② 위쪽에 빨간 안내가 있으면 → [전력 경고](#전력-경고) ③ 전원이 꺼짐이거나 밝기가 너무 낮지 않은지 확인하세요. |
| **색이 바뀌지 않아요 (흰색만 나와요)** | **LINE 12V** 는 흰색 전용 제품입니다. 밝기로 조절하세요. 기기 화면 **설정 → 장비** 에서 제품 종류를 확인할 수 있습니다. |
| **LED 끝부분이 안 켜지거나 개수가 안 맞아요** | 기기 화면 **설정 → LED 개수 → 자동 감지** 를 누르세요. → [라인조명 3장](라인조명-03-제어기-설정) |
| **그룹의 한 대만 따로 놀아요** | 그룹 연결 탭에서 그 기기가 **연결 끊김** 인지, **혼자** 가 켜져 있는지 확인하세요. → [공통 9장](공통-09-그룹-연결) |
| **조명이 저절로 깜빡이거나 꺼졌다 켜져요** &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | 아래 [조명 모습으로 알기](#조명-모습으로-알기)에서 같은 모습을 찾아보세요. 대부분 정상 동작입니다. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |

| 아이폰 **"LED 기기를 찾기 위해 로컬 네트워크 접근이 필요합니다."** | 아이폰이 묻는 권한 창입니다. 허용해야 기기를 찾을 수 있습니다(**허용 안 함** 을 누르지 마세요). 이미 거절했다면 **설정 → 개인정보 보호 및 보안 → 로컬 네트워크** 에서 켜세요. |
| **루틴은 4개까지 저장됩니다. 새로 만들려면 아래에서 하나를 삭제하세요.** · **루틴 4개 가득 참** &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | 루틴은 4개까지 저장됩니다. 쓰지 않는 루틴의 🗑 을 눌러 지운 뒤 만드세요. 🗑 은 확인 없이 **바로 삭제**됩니다. → [공통 7장](공통-07-루틴) &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |

### 기기 추가와 기기 화면 열기

| 화면에 뜬 문구 | 뜻 · 이렇게 하세요 |
|:---|:---|
| **값을 입력하세요** | IP로 직접 추가 창의 주소 칸이 비어 있습니다. 제어기 주소(예: `192.168.0.25`)를 넣으세요. → [공통 6장](공통-06-기기-관리) |
| **올바른 값을 입력하세요** | 주소에 띄어쓰기가 들어갔습니다. 빈칸을 지우세요. |
| **기기에 연결할 수 없습니다. 주소를 확인하세요.** | 입력한 주소에서 제어기가 응답하지 않습니다. 주소가 맞는지, 제어기가 켜져 있고 폰과 같은 WiFi 인지 확인한 뒤 **추가** 를 다시 누르세요. |
| **선택한 기기에 연결할 수 없습니다** · 전원이 켜져 있고 네트워크에 연결되어 있는지 확인하세요 | 기기 화면을 불러오지 못했습니다. 제어기 전원과 공유기를 확인하고 **다시 연결** 을 누르세요. 공유기를 껐다 켠 뒤라면 앱을 닫았다 다시 열어 기기를 새로 찾게 하세요. |
| **기기를 찾을 수 없음** · MAC 주소가 …인 기기를 목록에서 찾을 수 없습니다 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | 위젯에 연결해 둔 기기를 앱에서 삭제했습니다. **닫기** 를 누르고, 기기가 앱 홈에 다시 나타나면 위젯에서 기기를 다시 고르세요. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |

### 위젯

| 화면에 뜬 문구 | 뜻 · 이렇게 하세요 |
|:---|:---|
| 위젯에 **설정이 필요합니다** (빨간 글씨) | 위젯에 기기가 정해지지 않았거나, 정해 둔 기기를 앱에서 삭제했습니다. 위젯을 눌러 기기를 다시 고르세요. → [공통 8장](공통-08-앱-설정과-위젯) |

| 아이폰 위젯에 **Please configure** &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | 위젯에 보여 줄 기기 정보가 아직 없습니다. 앱을 열어 홈에 기기가 나타나게 한 뒤, 위젯을 길게 눌러 **위젯 편집** 에서 기기를 고르세요. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |

### 연결과 전송

| 화면에 뜬 문구 | 뜻 · 이렇게 하세요 |
|:---|:---|
| **기기 응답 대기 중…** (계속 뜸) | 기기 화면이 제어기의 응답을 기다리고 있습니다. 3초마다 스스로 다시 시도합니다. 계속 뜨면 제어기 전원과 공유기를 확인하세요. |
