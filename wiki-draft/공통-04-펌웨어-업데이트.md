# 공통 4. 펌웨어 업데이트 (OTA)

제어기의 펌웨어는 **앱에서 무선으로** 최신 버전으로 바꿀 수 있습니다.
업데이트 파일은 **폰이 인터넷에서 받아 제어기로 보내므로**, 폰이 인터넷이 되는 공유기 WiFi에 연결되어 있어야 합니다.

> ⚠️ 업데이트 중에는 **제어기 전원을 끄지 말고, 화면을 닫지 마세요.** 한 대에 약 1분 걸립니다.

## 그룹으로 묶인 제어기

그룹의 기준 제어기(마스터) 화면에서 업데이트하면 **그룹의 모든 제어기가 차례로 업데이트**됩니다. 다른 제어기(슬레이브)가 먼저, 마스터가 마지막입니다. 진행 창에 기기별로 `대기 → 전송 중… → 재부팅 확인 중… → 완료 ✓` 가 표시됩니다.

## 이런 안내가 나오면

| 안내 | 뜻과 해결 |
|---|---|
| **현재 최신 버전입니다** | 이미 최신입니다. 할 일이 없습니다. |
| **인터넷에 연결되어 있지 않습니다** | 폰이 제어기 WiFi(`DIYversity-…`)에 직접 연결된 상태입니다. 폰 WiFi를 **공유기**로 바꾼 뒤 앱에서 다시 하세요. |
| **기기에 연결할 수 없습니다** | 제어기 전원과 WiFi 연결을 확인하고 다시 시도하세요. |
| 기기별 **실패 ✗** | 해당 제어기의 전원·거리를 확인하고 업데이트를 다시 누르세요. |
